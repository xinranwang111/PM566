Question 1: Representative station for the US

What is the median station in terms of temperature, wind speed, and atmospheric pressure? Look for the three weather stations that best represent continental US using the quantile() function. Do these three coincide?

Description. The median station are 724280, 720377, 722197, for temperature, wind speed, and atmospheric pressure. They do not coincide.

get_station <- function(df, x){
  median.x <- quantile(df[[x]], 0.5, na.rm = TRUE)
  station.x <- df$USAFID[which.min(abs(df[[x]] - median.x))]
  return(station.x)
}
print(paste0("Station with median temperature: ", get_station(df, "temp")))

summary_byState_overall <- df %>%

Question 4: Means of means

Compute each state’s average temperature and use that to classify them according to the following criteria:

  • low: temp < 20

  • Mid: temp >= 20 and temp < 25

  • High: temp >= 25

Now generate a large summary table with states/observations split into the three categories listed above. For each group, compute the following:

  • Number of states

  • Number of entries (records)

  • Number of NA entries

  • Number of stations

  • Mean temperature

  • Mean wind-speed

  • Mean atmospheric pressure

summary_byTemp <- df %>%
  group_by(STATE) %>%
  mutate(mean.temp = mean(temp, na.rm = T)) %>%
  mutate(
    temp.cat = case_when(
      mean.temp < 20 ~ "low",
      mean.temp >= 20  & mean.temp < 25 ~ "mid",
      mean.temp >= 25 ~ "high",
      TRUE ~ NA_character_
    ) ) %>%
  ungroup()
summary_final <- summary_byTemp %>%
  mutate(temp.cat = factor(temp.cat, levels = c("low","mid", "high"))) %>%
  group_by(temp.cat) %>%
  summarize(num_state = length(unique(STATE)), 
            num_entries = length(temp), 
            num_NA_entries = sum(is.na(temp)), 
            num_station = length(unique(USAFID)), 
            mean_temp = mean(temp, na.rm = T), 
            mean_wind_sp = mean(wind.sp, na.rm = T), 
            mean_atm_pressure = mean(atm.press, na.rm = T)) %>%
  rename(`Temperature Categories` = temp.cat, 
         `Number of States` = num_state, 
         `Number of Entries` = num_entries, 
         `Number of NA Entries` = num_NA_entries, 
         `Number of Stations` = num_station, 
         `Mean Tempurature` = mean_temp, 
         `Mean Wind Speed` = mean_wind_sp, 
         `Mean Atmospheric Pressure` = mean_atm_pressure) %>%
  ungroup()
